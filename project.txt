Project Name: StarTip
Project Type: Creator Monetization / Web3 Payments
Blockchain: Stellar
Development Stage: MVP — Sprint 1
Platform: Web Application + Embeddable Tipping Widget
Supported Assets: XLM and USDC
Environment: Stellar Testnet

1. Project Overview
StarTip is a non-custodial, Stellar-powered tipping platform that enables content creators, streamers, educators, developers, and independent publishers to receive tips directly from supporters using XLM or USDC.
The platform provides creators with an embeddable tipping widget that can be added to websites, blogs, creator pages, and compatible livestream environments.
Supporters can select an asset, enter an amount, connect a Stellar wallet, and send a tip directly to the creator's wallet.
Creators will have access to a dashboard for tracking incoming tips, reviewing payment history, generating embed codes, and configuring live tip notifications for streaming demonstrations.
The goal is to make sending and receiving digital tips as simple as clicking a button, while using Stellar to enable fast, low-cost, direct payments.
The MVP will operate on Stellar Testnet using test assets.
2. Problem Being Solved
Creators often depend on centralized platforms and payment processors to receive tips and donations.
These platforms may introduce:
High processing fees for small payments.
Geographic payment restrictions.
Delayed access to earnings.
Limited control over payment infrastructure.
Difficulties accepting international payments.
Limited integration options for independent websites.
Fragmented donation and payment tracking.
StarTip addresses these problems by enabling direct wallet-to-wallet tipping on Stellar and providing a reusable payment widget that creators can integrate into their existing platforms.

4. Core User Journey
Creator Journey
Creator visits StarTip.
Connects their Stellar wallet.
Creates a creator profile.
Configures their tipping widget.
Selects supported payment assets.
Customizes the widget appearance.
Generates an embed code.
Adds the widget to their website or streaming page.
Receives tips directly into their wallet.
Monitors incoming payments and live alerts.
Supporter Journey
Supporter opens the creator's tipping widget.
Selects XLM or USDC.
Chooses a preset tip amount or enters a custom amount.
Optionally adds a display name and message.
Connects a compatible Stellar wallet.
Reviews payment details.
Approves the transaction.
Receives payment confirmation.
Creator receives a notification after the transaction is confirmed.
Core Product Flow:
Creator Creates Widget → Embeds Widget → Supporter Connects Wallet → Sends Tip → Stellar Confirms Payment → Dashboard Updates → Live Alert Appears

PART A — UI/UX DESIGN BRIEF
5. Design Objective
Design a modern, engaging, and easy-to-use tipping platform that makes supporting creators feel quick, personal, and rewarding.
The interface should combine the simplicity of modern creator monetization platforms with the transparency of Stellar payments.
The design must support two distinct experiences:
Creator Experience: A professional dashboard for configuring widgets, monitoring earnings, and managing notifications.
Supporter Experience: A lightweight tipping interface that makes sending a tip possible in a few simple steps.
Design Direction
Modern creator-economy aesthetic.
Clean and engaging visual identity.
Simple, friendly payment interface.
Strong emphasis on tip amounts and primary actions.
Professional dashboard design.
Mobile-first supporter experience.
Responsive layouts.
Clear transaction status indicators.
Suggested colors: dark navy, purple, electric blue, and subtle green accents.

Technical Note: StarTip does not require a Soroban smart contract for its core MVP. Direct XLM and USDC tipping can use native Stellar payment operations, reducing development complexity.
10. Module 1 — Stellar Payment Engine
Build the core payment infrastructure for sending tips directly to creators.
Required Functionality
Generate payment requests.
Support XLM payments.
Support Stellar USDC payments.
Validate recipient addresses.
Validate asset selection.
Validate payment amounts.
Generate unique tip references.
Construct Stellar payment transactions.
Request wallet signatures.
Submit signed transactions.
Monitor transaction settlement.
Record confirmed tips.
Prevent duplicate tip records.
Trigger alerts after successful payment confirmation.
Payment Flow
Supporter selects tip amount and asset.
Application generates a payment request.
Application constructs a Stellar transaction.
Supporter signs using their wallet.
Transaction is submitted.
Backend verifies transaction settlement.
Verified tip is recorded.
Creator dashboard updates.
Live notification is triggered.
Important Requirements
Tips must be sent directly to the creator's Stellar wallet.
StarTip must not custody supporter funds.
USDC payments must use the configured Stellar Testnet asset issuer.
Recipient wallets must support the selected asset.
The backend must verify the recipient, asset, amount, and payment reference before crediting a tip.
Duplicate transaction notifications must not create duplicate tip records.

The creator must be able to view incoming tips in a dashboard, access verified Stellar transaction records, and display confirmed tip notifications through a browser-based livestream overlay.
